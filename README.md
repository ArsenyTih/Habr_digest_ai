# Habr Digest AI

Проект персонального дайджеста статей с Хабра на базе ИИ-агентов.

## Как это устроено

1. **RSS-парсер** собирает свежие статьи с Хабра.
2. **Агент-сборщик** отсекает то, что уже было прочитано, и загружает полные тексты через **MCP-сервер** (`mcp-server-fetch`).
3. **Агент-аналитик** сопоставляет каждую статью с интересами пользователя, проверяет историю в **RAG** (ChromaDB) и ставит оценку от 1 до 10.
4. **Агент-редактор** отбирает лучшие статьи и собирает дайджест в HTML для Telegram.
5. **Telegram-бот** отправляет дайджест по расписанию (утро/вечер) или по команде `/digest`.

## Настройка Groq и лимиты модели

Для работы с моделью `openai/gpt-oss-120b` через Groq:

1. Зарегистрируйтесь на сайте [console.groq.com](https://console.groq.com/) и создайте API-ключ.
2. В файле `.env` укажите:
   ```env
   OPENAI_API_KEY=gsk_ваш_ключ
   OPENAI_MODEL=openai/gpt-oss-120b
   OPENAI_BASE_URL=https://api.groq.com/openai/v1
   ```

### Как проект защищен от превышения лимитов:
- `LLM_CONCURRENCY=1` — статьи обрабатываются строго по очереди, чтобы не превысить лимит 8K токенов в минуту.
- `ARTICLE_MAX_CHARS_FOR_LLM=2500` — статьи урезаются до 2500 символов (~800–1200 токенов), что с запасом укладывается в минутный лимит.
- `MAX_NEW_ARTICLES=5` — за один прогон анализируется не более 5 новых статей.
- `llm_delay_seconds=2.5` — автоматическая пауза между запросами к модели.
- Если сервис возвращает ошибку `429 (Too Many Requests)`, бот ждет указанное сервером время и повторяет запрос.

> **Примечание по RAG:** У Groq нет эндпоинта для эмбеддингов. Если в `.env` не указан отдельный `EMBEDDING_API_KEY` (например, от OpenAI), бот продолжит работать в обычном режиме, а RAG будет безопасно отключен.

## Быстрый старт

### 1. Виртуальное окружение и зависимости

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка файла .env

Скопируйте шаблон:
```powershell
copy .env.example .env
```

Заполните основные поля в `.env`:
- `OPENAI_API_KEY` — ключ от Groq (`gsk_...`) или OpenAI (`sk-...`)
- `OPENAI_BASE_URL` — `https://api.groq.com/openai/v1` (для Groq)
- `TELEGRAM_BOT_TOKEN` — токен бота из @BotFather
- `TELEGRAM_USER_ID` — ваш числовой ID из @userinfobot

### 3. Проверка компонентов

Проверка работы MCP-сервера:
```powershell
python mcp_client.py --list-tools
python mcp_client.py --fetch https://habr.com/ru/articles/
```

Проверка RSS:
```powershell
python rss_parser.py
```

Тестовый прогон компонентов:
```powershell
python dry_run_test.py
```

### 4. Запуск бота

```powershell
python main.py
```

## Команды Telegram-бота

- `/start` — приветствие и список команд
- `/digest` — собрать дайджест прямо сейчас
- `/digest_test` — тестовый запуск (без записи в базу и RAG)
- `/topics` — посмотреть список тем с весами
- `/addtopic <тема>` — добавить интерес (например: `/addtopic Нейросети`)
- `/removetopic <тема>` — удалить интерес
- `/history` — список последних отправленных статей
- `/feedback` — оценить подборку последнего дайджеста (кнопки 1–5)

При оценке 4–5 вес тем отправленных статей увеличивается, при оценке 1–2 — уменьшается, а статьи удаляются из RAG.
